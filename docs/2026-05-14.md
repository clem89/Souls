## 결정된 사항

- **개발 방식**: subagent-driven-development — 태스크별 구현 서브에이전트 + 스펙 리뷰 + 코드 품질 리뷰 2단계 검증
- **어셈블리**: Assembly-CSharp 방식 유지 (커스텀 asmdef 없음) — 프로토타입 단계 결정
- **이벤트 패턴**: 모든 컴포넌트에 `Debug.Assert + named method + OnDestroy 해제` 일관 적용
- **InputReader**: OnEnable마다 `_actions = new InputSystem_Actions()` 재생성 → 구독 누적 방지
- **공격 시스템**: 강공격/가드 제거, 자동 콤보만 유지 (디자인 스펙 확정)
