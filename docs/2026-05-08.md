## 결정된 사항
- **게임 방향**: 소울즈라이크 전투 + 로그라이크 루프 결합
- **기본 전투**: 공격(자동 콤보) + 회피(무적 프레임) + 패링(치명타). 가드는 제거 → 스킬로 대체 가능
- **스킬 슬롯**: 최대 4개 (Q/E/R/F), 스태미나와 별도 리소스 사용
- **스킬 성장**: 분기 업그레이드(같은 스킬 재획득 시 방향 선택) + 속성 시너지 마스터리
- **스킬 획득**: 방 클리어 시 3개 선택지, 픽 여부 관계없이 본 스킬 전부 풀 해금
- **메타 성장**: 스킬 풀 해금 방식 (영구 스탯 강화 없음)
- **던전**: 3D 프로시저럴, 방+복도 구조, 레이어 3개 클리어 = 런 성공
- **개발 순서**: Phase 1(전투) → Phase 2(던전) → Phase 3(스킬) → Phase 4(메타)
