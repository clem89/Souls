## 결정된 사항
- **Souls.Runtime.asmdef 도입**: `Assembly-CSharp`은 커스텀 asmdef에서 이름 참조 불가 → 전용 asmdef 생성으로 테스트 어셈블리와 분리
- **InputSystem_Actions.cs 수동 배치**: `Assets/Scripts/` 폴더(Souls.Runtime 범위) 안에 위치해야 InputReader와 EditModeTests 모두 참조 가능
- **ParryReceiver.CloseWindow()**: 패링 성공 시 즉시 적 공격 윈도우 강제 닫기 — 패링 후에도 피해 입는 버그 방지
- **이벤트 기반 락온 해제**: `DummyEnemy.OnDeath` 이벤트로 락온 해제 (Update 폴링 대비 성능·결합도 개선)
- **CombatHUD Start() 구독**: `StaminaController.Awake`에서 초기화되는 `Stamina` 프로퍼티를 `CombatHUD.Awake`에서 접근하면 순서 미보장 → `Start()`로 이동
