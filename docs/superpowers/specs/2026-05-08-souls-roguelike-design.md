# Souls-Like Roguelike — 설계 문서

**작성일:** 2026-05-08  
**프로젝트:** D:/dev/Souls (Unity URP)  
**장르:** 3D 소울즈라이크 + 로그라이크

---

## 1. 핵심 컨셉

소울즈라이크의 긴장감 있는 전투(회피·패링 중심) + 로그라이크의 스킬 빌드 조합 재미를 결합.  
기본기는 단순하게 유지하고, 스킬이 플레이 스타일을 결정하는 구조.

> "기본기로 살아남고, 스킬로 나만의 전투를 만든다"

---

## 2. 기본 전투 시스템

가드를 제거해 방어 선택지를 두 가지로 단순화. 모든 교전이 "피하거나 / 읽고 받아치거나"로 귀결.

| 입력 | 행동 | 비고 |
|------|------|------|
| LMB 연타 | 공격 (자동 콤보) | |
| Space | 회피 | 무적 프레임, 스태미나 소모 |
| RMB 탭 | 패링 | 성공 시 치명타 (Riposte) |
| Q / E / R / F | 스킬 슬롯 | 별도 리소스 소모 |
| 휠 클릭 | 락온 | |

**리소스**
- 스태미나: 회피에만 소모. 가드 없으므로 관리가 단순.
- 스킬 리소스: 스태미나와 별도. 스태미나 고갈 상태에서도 스킬 사용 가능.

**제거된 기본기**
- 강공격 / 약공격 구분 없음 (스킬로 대체 가능)
- 가드 없음 (가드형 스킬로 구현 가능)
- 포이즈 / 그로기 시스템 없음 (추후 검토)

---

## 3. 스킬 시스템

### 3.1 슬롯

- 덱 슬롯: **최대 4개**
- 슬롯이 꽉 찬 상태에서 새 스킬 획득 시 → 교체 또는 버리기 선택

### 3.2 스킬 구조

각 스킬은 다음을 가짐:
- **속성 태그**: `[화염]`, `[냉기]`, `[번개]`, `[암흑]`, `[방어]` 등
- **분기 업그레이드**: 같은 스킬을 보상으로 다시 받으면 2가지 방향 중 선택
- **쿨다운 / 효과**

### 3.3 속성 시너지 (마스터리)

같은 태그 스킬 수에 따라 패시브 보너스 발동:

| 조건 | 마스터리 효과 (예시) |
|------|---------------------|
| `[화염]` 2개 이상 | 공격 시 화상 스택 부여 |
| `[화염]` 4개 (풀덱) | 패링 성공 시 화염 폭발 |
| `[냉기]` 2개 이상 | 회피 후 주변 빙결 |
| `[방어]` 2개 이상 | 가드 스킬 쿨다운 -30% |

**슬롯 제한의 전략적 역할**
- 4슬롯 동속성 = 마스터리 풀 발동, 빌드 다양성 포기
- 2+2 혼합 = 두 마스터리 절반 발동, 안정적
- 이 긴장감이 매 보상 선택의 핵심

### 3.4 스킬 획득 (런 중)

- 방 클리어 시 3개 선택지 등장 → 1개 픽
- 선택지에 **이미 보유한 스킬** 등장 시 → 해당 슬롯을 그 자리에서 분기 업그레이드 (교체 없음)
- 선택지에 **새 스킬** 등장 시 → 빈 슬롯에 추가. 덱이 꽉 찼으면 기존 스킬과 교체 또는 버리기 선택
- 선택지에 나온 스킬 3개 모두 → **픽 여부와 관계없이** 풀에 영구 해금

---

## 4. 메타 성장

**"본 것은 해금"** 원칙:
- 방 보상 선택지에 등장한 스킬은 모두 풀에 영구 등록
- 다음 런부터 해당 스킬이 선택지로 나올 수 있음
- 초반 런: 풀이 좁아 선택지 반복 → 업그레이드 기회 많음
- 런이 쌓일수록: 풀이 넓어져 빌드 다양성 증가

**특별 해금:**
- 보스/엘리트 처치 → 희귀 스킬 풀에 추가

**기지 화면 (런 사이):**
- 스킬 풀 현황 확인
- 시작 스킬 1개 선택
- 다음 런 시작

---

## 5. 던전 구조

**런 1판 = 3D 오픈 던전 레이어**

```
[시작 지점]
    ↓
[일반 방 x N]  ← 적 처치 → 스킬 보상 선택
    ↓
[엘리트 방]   ← 강한 적, 희귀 스킬 해금 기회
    ↓
[보스 방]     ← 보스 처치 → 다음 레이어
```

- 방들은 복도로 연결된 3D 공간 (완전 오픈 지형 아님)
- 방 크기·형태는 프리셋 풀에서 랜덤 배치
- 적 배치·스킬 보상은 런마다 랜덤
- 레이어 3개 클리어 = 런 성공
- 사망 = 런 종료, 메타 성장 후 다음 런

## 6. 개발 Phase

| Phase | 목표 | 핵심 결과물 |
|-------|------|------------|
| 1 | 전투 프로토타입 | 공격·회피·패링·스태미나·락온 동작 씬 |
| 2 | 오픈 던전 | 프로시저럴 방 배치, 적 배치, 스킬 보상 UI |
| 3 | 스킬 시스템 | 액티브 슬롯, 분기 업그레이드, 속성 시너지 |
| 4 | 메타 성장 | 스킬 풀 해금, 기지 화면 |

**MVP 범위 (Phase 1~2):**
- 단일 레이어, 방 5~8개 + 보스 1개
- 스킬 3~4종으로 시스템 검증
